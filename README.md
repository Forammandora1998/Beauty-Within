# Beauty Within

Complete React + Vite storefront prototype.

## Run locally
`npm install` then `npm run dev`

## Videos
No video files were available in the supplied chat assets when this package was built. Add MP4/WebM files to `public/videos/`; the project can then be extended to show them in product galleries.

## Important
Cart, checkout and custom Nail Lab submission are front-end prototypes and do not yet process payments or permanently upload customer files.
